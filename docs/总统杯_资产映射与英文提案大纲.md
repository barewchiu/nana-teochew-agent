## 3. 英文提案大纲（建议结构）

可按报名表字段裁剪；路演 PPT 同结构压缩为 6–8 页。

### 3.1 Title & one-liner

- **Title:** Nana Teochew Companion — Mother-Tongue AI for Dialect-Speaking Elders  
- **One-liner:** A Teochew-first care companion that lets a grandmother receive family messages, reminders, and opera/radio without learning Mandarin apps—backed by a measured dialect ASR roadmap.

### 3.2 Problem（问题）

英文要点：

1. AI assistants assume Mandarin (or English); dialect-only elders are locked out.  
2. Complex UIs create fear and dependency on younger relatives.  
3. Care needs (meds, loneliness, family voice) are daily, not “nice to have.”  
4. Cultural media (Teochew opera / local radio) is hard to reach via search-heavy apps.

对应资产：A1。

### 3.3 Beneficiaries & public value（受益者与公共价值）

- Primary: dialect-only older adults (Teochew pilot).  
- Secondary: families abroad/out-of-town; community care workers.  
- Public value: **digital inclusion**, healthier aging at home, cultural continuity.  
- Scalability: same pattern for Taiwanese Hokkien, Hakka, other Sinitic dialects / minority languages.

对应资产：A1–A5。

### 3.4 Solution（解方）

四层架构（英文可画一张图）：

```
[ Accessible 3-button UI ]
        ↓
[ Intent + memory + mishear repair ]  ← product brain
        ↓
[ Ear: cloud Mandarin ASR now → Teochew ASR (LoRA) next ]
        ↓
[ Voice: family-recorded Teochew replies + media ]
```

功能块：

1. **Family bridge** — Mandarin message → Teochew audio.  
2. **Companion talk** — Teochew intents + short memory + scene buttons.  
3. **Care nudge** — medication reminder on open.  
4. **Culture** — opera clips + local FM.  
5. **Dialect ear R&D** — holdout-gated ASR improvement.

对应资产：A2–A14。

### 3.5 How it works (demo script · 1–2 min video旁白)

英文旁白草稿：

> Meet Nana. She speaks only Teochew.  
> First, a medication reminder plays in her language.  
> Second, she taps blue—hears her grandson’s message in Teochew.  
> Third, she taps red—scene buttons or LIVE speech: “Have you eaten?”—and hears a warm Teochew reply.  
> Fourth, green—Teochew opera or Chenghai radio, no complicated search.  
> Behind the scenes, we measured Mandarin ASR on real Teochew audio at about 41% intent accuracy, then fine-tuned a Teochew model to about 94% on a locked holdout—so inclusion is not only a UI story, but an ear we can improve.

对应资产：A2–A9, A13；演示优先快捷钮。

### 3.6 Evidence & metrics（证据）

| Metric | Number | Note |
| --- | ---: | --- |
| Intent on gold labels | 100% | Upper bound of NLU layer |
| Groq Mandarin Whisper on Teochew holdout | 40.6% | Baseline exclusion |
| Open Teochew Whisper zero-shot | 50.0% | Better, not enough |
| L1 LoRA (46 train clips) | **93.8%** | Same 32-clip locked holdout |
| Live product | Deployed URL | Prototype online |

对应资产：A10–A13。

### 3.7 Innovation（创新点）

1. **Person-first inclusion** then generalize—not platform-first.  
2. **Hybrid dialect stack:** repair + intent + recorded voice + ASR R&D.  
3. **Evaluation discipline:** locked holdout, never train on test.  
4. **Family-in-the-loop data:** relatives record replies and commands.

### 3.8 Roadmap（路线图）

| Horizon | Plan |
| --- | --- |
| Now | Stable demo; public prototype; English materials |
| Next | Wire Teochew ASR into LIVE (`TEOCHEW_ASR_URL`); more L1/L2 data |
| Scale | Dialect packs (Hokkien/Hakka…); care-org pilots; privacy-preserving data |

对应债务：复盘 §7.4。

### 3.9 Team, ethics, risks（团队 / 伦理 / 风险）

- Privacy: elder audio default local; no secrets in git.  
- Consent: family-recorded voices; real-elder storytelling with respect.  
- Risk: ASR domain shift; free hosting cold-start—mitigate with scene buttons + warmer hosting if finalist.  
- Team: fill per handbook (3–10; nationality rules if International Track).

### 3.10 Ask / next partnership（需要的支持）

英文可写：open dialect datasets, care-institution pilot sites, compute for ASR, localization partners.
