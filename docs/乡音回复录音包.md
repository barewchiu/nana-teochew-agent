# 乡音回复录音包（P1）

家人用**潮汕话**录短句，命中意图时优先播原声，而不是普通话 TTS。

## 目录

`nana-agent/public/audio/replies/`

代码已接通：

- 后端 `INTENT_REPLIES` → `/audio/replies/{intent}.m4a`
- 前端 `REPLY_VOICE_PACK` / `resolveChatAudio`
- DEMO 轮次与 LIVE KB 命中共用同一路径

## 操作

1. 手机安静环境录潮汕话 → 导出 `m4a`
2. 覆盖或新增到 `public/audio/replies/`
3. 提交推送后 Render 自动上线

更细的表格见 `nana-agent/public/audio/replies/README.md`。
