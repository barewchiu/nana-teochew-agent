# P3 · 短多轮记忆

LIVE 对话会把最近约 3 轮（最多 6 条消息）发给后端，承接上一轮话题。

## 行为

1. 界面显示：`小管家记得：刚才在讲「吃药」`
2. 上一轮讲吃药后，再说「食了 / 还没」→ 续话确认，而不是当新话题乱答  
3. 上一轮讲天气后，再说「热 / 冷 / 落雨」→ 继续关心天气  
4. 短附和「好 / 嗯」→ 留在刚才话题  
5. 明确新意图（如从吃药转到潮剧）→ 切换话题  

## 自测建议

1. LIVE：先说「阿嫲爱食药未？」  
2. 再短说「食了」→ 应出现续话 /「接着刚才说」  
3. 再说「想听潮剧」→ 应切换到潮剧，而不是继续吃药

- `src/App.jsx`：提交 history + 记忆提示条
