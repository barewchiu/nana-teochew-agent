# P4 · 场景快捷钮

聊天页提供大字场景钮，**不经过 Whisper**，一点即命中乡音回复包，路演更稳。

## 用法

1. 打开「跟管家讲话」  
2. 点「吃饭 / 吃药 / 想阿公 / 天气 / 潮剧 / 孙子 / 身体 / 想你」  
3. 若刚讲过吃药，会出现「接着说：食了」续话钮（配合 P3）  

麦克风 LIVE/DEMO 仍可照常使用；快捷钮适合评委演示。
